# 🚦 Traffic Sign Recognition (CNN)  

This project focuses on **classifying traffic signs** using the **German Traffic Sign Recognition Benchmark (GTSRB)** dataset from Kaggle.  
It applies **Deep Learning (CNN)** techniques with image preprocessing and evaluation.  

---

## 🚀 Project Workflow  
- 📂 **Data Preprocessing** → Image resizing, normalization, and dataset preparation  
- 🔍 **Exploratory Data Analysis (EDA)** → Class distribution & visualization  
- 🧠 **Model Training** → Custom CNN architecture with Keras/TensorFlow  
- 🌀 **Data Augmentation** → Improve generalization using flips, rotations, zoom  
- 🤖 **Transfer Learning** → MobileNet for performance comparison  
- 📊 **Evaluation** → Accuracy, Confusion Matrix, Classification Report  

---
